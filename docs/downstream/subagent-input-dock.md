# 原生子代理卡片固定区

私有下游提供 `subagentInputDock`，默认关闭。在 `/settings` 的「对话与输入」中开启「运行中的子代理固定在输入框上方」，或将以下字段合入 `~/.dsh-tui/settings.json` 的现有 `values`（保留其他设置）：

```json
{
  "version": 1,
  "values": {
    "subagentInputDock": true
  }
}
```

设置页立即生效；外部编辑文件后重启。DSH CLI 插件挂载也支持 `config.subagentInputDock: true`。

## 一份实时卡片，原位置只留引用

启用后，同一个原生 `SubagentMessage` 卡片改在输入框上方绘制，而不是在底部再造另一种简卡。保留原卡片的标题、状态/模型等元数据、工具行、活动流水、详情点击和 `⤢` 主屏查看动作。

运行中的历史位置只显示无动画、无活动正文的一行引用。它保留原行锚点，可点击进入详情。任务完成、失败、取消或状态未知时退出固定区，原位置恢复正常历史卡片。只改变展示，不删除、复制或改写会话事实，不移动持久化记录，也不改变子代理执行。

新的主输出、转录滚动和打开子代理侧栏都不会带走固定区。全屏编辑器或替代输入场景暂时占用输入区时，固定区让位，历史位置恢复原卡片，避免隐藏唯一可读视图。关闭配置也恢复原有聊天展示。inline 沿用现有的无鼠标限制，使用 Ctrl+A 进入子代理面板。

## 原卡片的紧凑与折叠

固定区整体是一张卡面：所有并行成员共用背景、边框和内边距，成员之间不再各画一圈边框或留透明间隔。每个条目仍使用同一个原生卡片组件，保留自己的标题、状态和查看动作，不另造简卡。legacy 默认仍透明，pi-like 和显式背景设置由整个区域统一绘制。

按可用空间选择原卡片布局：完整布局保留工具行及三行活动流水；紧凑布局保留工具行及最新一行活动；折叠布局保留原卡片表头。无工具记录时回复直接紧贴标题，空闲工具位留在条目末尾，以保持输入框及后续成员位置稳定；有工具时首行展示最近工具，后面是回复。回复预览把换行显示为空格，每行固定一个显示行且不收缩，不因流式内容重新分配上下空白。会话事实中的原文和换行不变。

卡面使用原有 `cardStyles.kinds.subagent`：pi-like 的运行态背景和深浅主题，以及公共/按类型的边框、颜色、横纵内边距和间隔覆盖均沿用原实现。legacy 默认保持透明、无边框。

高度预算包含整张外层卡面的 chrome 和间隔，只扣一次，最多八行，并受终端高度约四分之一及其他内容约 12 行预留限制。任务过多时折叠原卡片，并明确显示总运行数、可见数和其余数量；点击数量打开既有子代理面板。例如 100×40 的 pi-like 演示追加后共 14 个任务，可能显示「14 running · 6 shown · 8 folded」。小终端或过大的个人边框/内边距连一个折叠表头都容不下时，只显示打开面板的数量入口，不绘制被裁掉的半张任务卡。

## 隔离演示

在本仓库根目录运行：

```sh
node --import tsx/esm scripts/downstream/subagent-dock-demo.tsx
node --import tsx/esm scripts/downstream/subagent-dock-demo.tsx --inline
```

默认 pi-like，立即显示 Review / Tests 两个并行任务。每个成员从模拟 `Read` 调用开始，每 1.5 秒交替完成当前工具、启动下一个工具，循环展示 `Read` → `✓Read` → `✓Read · Grep` → `✓Grep`，下面仍是模型回复。single、parallel、workflow 及追加成员都提供工具事件；阶段推进/结束会先结算尚在运行的工具。工具行来自真实投影后的 `toolCalls`，不是把正文改成工具名字；这些事件仅为演示，不实际读取文件、执行命令或调用模型。建议至少 60×24，100×40 可观察更多正文；折叠布局仍只显示表头。加 `--legacy` 可从旧风格开始。

| 演示快捷键 | 操作 |
| --- | --- |
| Alt+6 | 单个子代理 |
| Alt+7 | 两个并行子代理（默认） |
| Alt+8 | workflow：规划 → 两路审查 → 汇总 |
| Alt+9 | 手动推进 workflow 阶段，结算当前阶段所有成员 |
| Alt+5 | legacy / pi-like / pi-like＋描边内边距 |
| Alt+1 | 显示/隐藏固定区 |
| Alt+2 | 所有场景追加 12 个并行成员，包括 workflow |
| Alt+3 | 完成当前所有任务 |
| Alt+4 | 重置当前场景 |
| Ctrl+C | 退出并清理临时 HOME |

切换/重置场景会清空演示草稿并重建隔离会话。workflow 使用假子会话，通过真实 DSH workflow 成员和子输出事件的既有投影展示；不执行真正的 workflow 工具、不调用模型或读取真实凭据。额外 workflow 成员也在下一阶段推进时结算；已完成流程追加任务时标为 Parallel extension，继续推进即可结算。


## 维护接缝

`Chat` 用同一条件挂载固定区并启用历史引用；`MessageList` 的行 memo/高度签名包含该条件，开关、终态变化时正确重测。运行中的静态引用始终只有一行，工具/输出数量变化不再令它的高度缓存失效，以免离屏占位高度变化带动 inline 输入区。原卡片的可选 density 只影响固定区，缺省参数保持原转录行为。数据直接读取既有 `SubagentState` / `SubagentRow`，不在显示层重造会话事实。

升级或修改这些接缝时，运行 `verify-subagent-reference-height.tsx` 检查离屏引用的虚拟高度与输入位置不随活动变化，再运行 `verify-subagent-dock-stability.tsx` 检查含换行的连续更新、工具位切换、正文槽位和共享卡面，并运行 `verify-original-subagent-dock.tsx`，实际检查 workflow 原卡片标题在新主输出之后、输入之前，而不是只检查名字是否出现。同时复验开关、静态引用、终态恢复、`⤢` 查看、pi-like/legacy 卡面、低高度和 Alt+2 的阶段结算。
