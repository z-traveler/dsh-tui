# 完成技能提及交接中的全部 TUI 宿主能力

用户澄清本轮按工作区 `dsh-skill-mention-tui-requirements.md` 完成全部 TUI 侧支持，而非仅通用 notice：包括通用输入补全插件接缝、成功技能加载卡片与失败上下文通知、生命周期和隔离入口验收，以及供插件方接入的类型与契约文档；本记录替代 ADR-0001 的范围限制。

分工遵循该交接：宿主管理菜单、按键、草稿范围替换、异步结果有效性及注册清理，技能目录查询、权限、匹配排序和规范插入文本由技能插件提供，不在 TUI 生产代码中内置技能规则或复制主输入框；使用可安装、禁用和卸载的 provider 验证正式公开接缝，不将旧宿主补丁分支视作插件交付。

上下文通知依据通用 `source.form: 'notice'` 与 `summary` 消费，不按插件来源名字特判；摘要与完整正文来自持久会话事实，保留既有专属呈现的优先级以避免重复，不伪造命令或工具执行，也不改变原消息的模型可见性。
