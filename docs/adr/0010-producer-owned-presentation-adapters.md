# 业务包提供分端展示适配，TUI 统一承载卡片

用户确认采用 core 生产领域事实、Web/TUI 分端提供展示适配的方向；同一业务包可以组织这三个入口，但入口的具体加载声明不在本记录中预设。统一消费接口主要约束 TUI 展示适配与卡片宿主之间的交互，不强求所有 core 生产者直接写入同一种展示数据，也不要求 Web/TUI 共享组件实现。

TUI 展示适配可以理解业务数据并组织标题、摘要、正文等展示内容，不能任意绘制 React 组件或接管按键。主题、外壳、折叠、选中、滚动、长正文和更新由卡片宿主统一负责；业务计数与事实语义仍由 core 拥有。现有技能展示迁移遵循这一边界，不修改模型输入或增加重复事实。

本决策解决了先前未决的“是否强求无需生产者展示适配”问题：不强求，允许业务包提供适配。生产者卸载后的历史降级、独立 log-only 内容的持久化载体及其稳定性需在后续契约中明确，不能以组件复用代替持久事实契约。其余可逆实现细节由实现方选择，只有 P0 级别的取舍提交用户决策。
