# 插件浮窗的布局、外观与输入所有权独立控制

为响应第二轮通用定制需求，浮窗类型可声明默认选项，每次打开叠加实例覆盖，已打开的实例可原地更新。尺寸、锚点、偏移、边距及响应式可见性参考 Pi OverlayOptions；外观仍由本包现有渲染原语实现。默认保留首轮居中卡片，显式关闭宿主 chrome 可承载单行等完全自绘内容。不修改渲染器，不支持或模拟 alpha。

显示窗口不必取得键盘。普通窗口默认取得输入，被动窗口默认只展示；显式聚焦后才能接管输入。输入所有权只有一个来源，拥有输入的窗口最后绘制，不能被新开被动窗口遮成不可见的输入目标。取消聚焦、手动隐藏和响应式不可见均不销毁组件；关闭后任何迟到的句柄操作不得复活窗口。

实际可见性和几何由聊天宿主投影，运行时不从插件配置推测屏幕事实。定位使用真实可见聊天帧；默认尺寸预算保留原有短 inline 帧口径，不为浮窗扩张聊天布局。内容获得扣除装饰后的尺寸，bounds 为只读的帧内坐标，不冒称 inline 终端绝对坐标。

新能力通过 `modalOptionsVersion === 1` 检测，避免首轮宿主虽有 `openModal` 却静默忽略新增参数。未知字段或无效选项明确报错，更新失败不部分生效；undefined 删除实例覆盖、回落到类型默认，样式按字段合并。

本决策扩展[窗口栈与宿主让位规则](0015-plugin-modal-stack-and-host-interruptions.md)，不改变作用域所有权、关键宿主交互优先、会话切换清栈或旧全屏场景行为。完整参数与限制见[插件浮窗指南](../downstream/plugin-modals.md)。
