# 补全查询归宿主、覆盖真实启动入口

补全沿用现有 Cordis activation 注册与清理机制，不另建授权体系；provider 仅接收当前空白 token、局部光标和只读会话身份，不得到任意草稿写入或提交能力，替换范围止于当前光标以保留后文。

默认启动页与聊天 composer 共同消费同一个补全 facade、异步生命周期 hook 和菜单组件；真实插件入口验收发现只接 PromptInput 会漏掉默认启动页，故在两个既有编辑边界分别接入，不复制输入框或技能业务逻辑。

同次查询等待参与来源全部返回再按来源优先级形成菜单，避免迟到结果偷换选中身份；取消、来源变化及卸载立即终止宿主等待，即使 provider 不配合 signal，慢来源在未取消时仍会延迟菜单，此版本不增加查询超时配置。
