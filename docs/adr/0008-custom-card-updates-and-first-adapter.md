# 自定义卡片消费接口支持更新，以技能展示作为首个适配

用户确认通用卡片不能限定为不可变快照：技能指令与上下文报告可以是静态内容，进度类内容需要更新同一卡片的展示。接口必须同时容纳静态与可更新内容；更新的历史保存、恢复与终态规则尚未确定，不将展示更新解释成覆盖已有持久事实，也不将技能指令改成可变领域事实。

本轮交付可实际接入的消费契约，包括文档、类型与运行时校验、接入路径、通用展示和合成生产者端到端验证；不修改外部生产者，不兼容 dsh-context 私有协议。现有技能卡片作为内置适配迁移到新展示机制，保留技能加载流程、原有事实及模型可见性，不另写重复记录。具体映射位置由现有分层决定，不预设只修改事件定义即可完成。

是否采用无需生产者 renderer 的自包含展示数据仍未决；须先调研官方 DSH Web 的扩展与自定义渲染契约，再由用户决定 Web/TUI 的统一边界。
