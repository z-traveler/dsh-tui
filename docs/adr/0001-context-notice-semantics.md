# 按通用上下文形态呈现通知

范围已由用户澄清为完整 TUI 接入需求，见 [ADR-0002](0002-complete-skill-mention-tui-support.md)；下述来源与形态解耦、真源投影原则继续保留。

TUI 依据 DSH 声明的 `source.form: 'notice'` 与 `summary` 消费上下文通知，不依据插件的 `source.kind` 名字决定是否显示；来源标识仅说明内容由谁产生，使新来源及生产者已卸载的历史记录仍可使用同一呈现契约。

摘要与正文来自持久会话事实，不伪造命令或工具执行，不改变原消息的模型可见性；skill-mention 的现有失败消息已满足此通用语义，不要求它重写成功或失败协议。

本轮只补通用 notice 消费，保留既有专属呈现的优先级以避免重复；输入补全扩展、其他上下文形态与严重级别标准化不在本轮范围。
