# Powerline 输入区域

## 目标与来源

以用户当前本机 Pi + pi-powerline-footer 配置和实现为体验参照，对齐 HUD、工作状态行、
输入框边框与间距。消息卡片、侧栏及 subagent/workflow 本轮不调整。
来源归属只写入文档；新增代码、配置键、符号与注释使用宿主中性的命名。

## 风格与配置

- 提供 `native` / `powerline` 风格，默认 `native` 保持上游行为，本机选择 `powerline`。
- 新风格提供一致预设，并允许覆盖字段显隐、左右分组/顺序、分隔符、配色/模型匹配、
  图标、位置、间距与溢出规则；不靠硬编码个人偏好改出厂默认值。
- 新逻辑放独立模块，上游只加必要接入点；不复制原渲染器、不做无关重构或依赖升级。

## Powerline 外观与行为

- 主 HUD 融入输入框顶边，单行输入与圆角底边融合；多行保留左右边线和对应内边距。
  会话入口与草稿编辑按钮默认不占输入行，功能仍经现有命令/快捷键可用。
- 标识默认 `🐋`，允许替换；左侧依次为标识、模型:强度（带适用的订阅窗口）、上下文、费用、Shell 模式、
  末级目录、Git、扩展状态；右侧保留主 Agent 字段能力。没有真实对应数据的字段不伪造、不占位。
  不为显示字段新增 Shell 模式功能。
- 模型与强度合为不可拆分的一段。模型家族色沿用本机参考：DeepSeek 蓝、GPT 白、Claude 黄；
  目录青色，Git 按干净/脏状态着色，高思考强度使用静态逐字彩虹色，不新增扫光动画。
  输入框边框使用统一强调色，不随忙碌/错误状态变色。颜色和图标支持配置及 ASCII 回退。
  模型图标可按模型 ID 的匹配规则单独配置，按列表首个匹配生效；未匹配时使用原有通用图标 ``。
- 上下文默认显示图标、百分比和容量，如 `◫ 25.0%/100k`；超过 70% 黄、超过 90% 红。
  格式与阈值可配置；不显示独立进度条，悬停也不把数字换成进度条。
- Git 显示分支及 `*3 +2 ?1` 形式的未暂存/已暂存/未跟踪计数，异步缓存只读查询；
  不可读时不伪装成干净。路径支持末级/缩略/完整显示。
- 布局先预留右侧，再按左侧顺序放入完整字段；从首个放不下的字段起转入输入框下方溢出行。
  默认 `drop`：第二行遇到放不下的字段即停止；可配置 `wrap`。不按臆定重要性重排，也不统一压缩字段凑首行。
- 工作状态在 HUD 上方，使用紧凑 spinner、真实阶段描述和中断提示；保留耗时、错误/重试原因。
  额外 token/速度计数默认隐藏，可配置。运行态在状态文字前后各留一空行，空闲时工作行和两侧留白一起撤下。
  输入框下方保留一空行，与溢出字段或后续内容隔开；这属于布局留白，不为悬停提示预留空白行。
- 订阅窗口采用宿主已有 rate-limit 数据，按 [本机参考](reference.md) 紧跟模型/强度，同属一个不可拆分字段，不新增独立额度栏。
  Codex 仅显示 `week:80% (6d)`；Claude 订阅依次显示 `5h:80% (2h) week:24% (6d)`；其他后端和缺失窗口不显示、不占位。
  剩余值低于 10 红、低于 25 黄，其余绿，重置括号淡显；倒计时向上取整为 m/h/d，小于一分钟显示 now。不依赖费用字段，不误标成金额，不自行补满额度。
  不新增网络请求或登录。离线演示区分 DeepSeek/Codex/Claude 场景，不向 DeepSeek 塞订阅数据，演示可保留用户认可的 ◆/◉/✳ 自定义映射，但不作为参考自带或官方品牌默认值；不同显示宽度必须补齐统一槽位。
- 审批、问题、异常等按需使用提示/原生面板，危险权限必须明确可见。
  详情使用按需浮层，不新增固定空白行；保留模型、强度等点击入口。

## 数据与插件边界

- 费用按 dsh-TUI 现有处理，不强求参考实现的口径/币种，不新增前端换算或计费规则。
  其他指标亦复用宿主真源，不在新 HUD 重算领域事实。
- 普通插件字段使用新 HUD 样式；尊重其显隐、槽位、语义色、点击、详情和生命周期。
  富状态视图保留独立呈现区域，侧栏、场景、对话框、通知及其他插件接缝不得退化。
  实现细节由 Agent 按协议选择，不因外观统一解析插件文字或绕过接口。
  `setField` 字段保持协议规定的单行与长度/宽度预算；主字段溢出不让插件字段变成多行组件。

## 验收与交付

- 原生默认无展示回归；新风格配置可保存/重载/切换，非法配置安全回落。
- 切换布局不丢草稿、光标或焦点；验证 inline/fullscreen、窄屏、CJK、左右组、溢出与插件字段。
- 测试边界仍为配置解析/持久化及实际终端渲染；补充必要的只读 Git fixture。
  开发只跑定向检查与必要编译，全量门禁留到发布前。
- 准备无凭据隔离应用及固定指标演示，记录证据与剩余人工验收到 [delivery.md](delivery.md)。
  旧候选版的验证不证明本规格已实现。
- 已确认方向下，可逆实现细节自主决定；只在 P0 级决策、不可逆风险或授权边界处询问用户。
  提交、推送、发布和稳定安装切换分别需要授权。
